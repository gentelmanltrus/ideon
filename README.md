# ideon
Ideon is a web platform designed to help people turn their ideas into reality. Platform where users share ideas for apps, games, and products, while others rate their usefulness, creativity, and feasibility.

**Backend:**
 * ASP.NET Core Web API - free, cross platform open source framework, essential for creating web application
 * C# - virtual machine based language ideal for web development

**Database:**
 * PostgreSQL - useful tool for organizing database

**Version Control:**
 * Git
 * GitHub

**Development:**
 * VS Code - great multi language IDE integrated with Github

**API Testing:**
 * Swagger - great tool to see how web app works on localhost



## End-to-end user scenario:

Amina opens Ideon, discovers ideas from other users, and creates a post: “Imagine a game where your real-life choices change the storyline.” She selects the "Game" category and publishes it. Other users evaluate the idea based on originality, feasibility, and usefulness, and leave comments with suggestions. Amina uses the feedback to improve her idea and marks it “Looking for a Builder” to find potential collaborators.

**Result:** Amina turns a simple idea into a validated concept with community feedback and potential collaborators.
